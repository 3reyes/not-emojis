# Security Policy

## Supported versions

Security fixes are made to the latest published release. Users should keep their action reference current.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. When this project is hosted on GitHub, use **Security → Report a vulnerability** to contact the maintainers privately. Repository maintainers should enable GitHub's private vulnerability reporting before publishing releases.

Please include the affected version, impact, and steps to reproduce. The maintainers will acknowledge the report and coordinate a fix and disclosure with the reporter.
